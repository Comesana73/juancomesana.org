Reading the matrix

Row chooses a row and Column chooses a column. In a general game each cell shows two payoffs: Row’s first, Column’s second.

In a zero-sum game each cell shows only Row’s payoff. Column gets the negative of it, so Row wants the numbers high and Column wants them low.

Click a strategy name in the matrix editor to rename it (C, D, Stag, Hare…). Payoffs can be whole numbers, decimals or fractions. Press Enter or click Done to use it.
